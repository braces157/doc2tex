# R07 caption numbering and explicit references

Implemented 16 October 2026 (Asia/Bangkok), after R06 was reviewed and merged in PR #17. PR review and final-head CI remain the merge gate.

The synthetic `caption-references.docx` fixture and generator were added before changing conversion. It contains two figures with repeated caption text, a table, bookmarks around SEQ number fields, simple/complex numeric REF fields, ordinary prose, PAGEREF, a missing target and a detached caption. Probes against pinned Pandoc 3.12.1 show that simple fields lose cached text, while equivalent complex fields retain bookmark links.

Normalize field structure in a conversion-only DOCX copy, preserving the uploaded original. Use a [Pandoc Lua structural filter](https://pandoc.org/lua-filters.html) on actual Figure/Table captions and explicit field-derived links. Numeric body REF relationships with supported switches and unique caption-owned bookmarks can become generated safe labels/references. Unsupported fields, missing/ambiguous targets and detached ownership retain readable cached text and warnings. Ordinary “see Figure 1” prose is not a semantic reference.

Represent a detected literal caption-number prefix structurally with a small identity macro so conversion preserves its visible text. A bounded LaTeX structural scanner will propose removing that prefix only inside numbered figure/table captions, with exact before/after source. Legacy plaintext caption prefixes can be handled conservatively in the same caption context. Accepted repairs use current revision/source-hash checks and the R03 snapshot save path; cancellation does not change source and conflicts cannot overwrite newer text.

Validate parser/normalizer/filter fixtures and actual Article/Report PDF captions/references, inspect PDF output, and test browser preview/apply/cancel/restore behavior. Do not claim unsupported Word field semantics or infer references from matching caption/prose strings.

The implementation uses unique field tooltip markers in the conversion copy because PAGEREF and REF may share both target and numeric cached text. Only metadata-verified links become references. Original uploaded bytes are preserved. Labels reserve existing AST identifiers and use deterministic bookmark-derived names with collision suffixes; repeated captions remain separate owners.
